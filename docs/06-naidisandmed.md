## Kontrollitud

Skeem ja näidisandmed laaditi lokaalsesse PostgreSQL 16-sse (Supabase `auth` skeem asendatud tüngaga):

- `data_gaps(2027)` tagastab täpselt 3 lünka (S1.2 mõõdik puudub, matemaatika algtase puudub, HARNO autonoomia 2027 sisestamata)
- `overdue_activities('2027-10-01')` tagastab 3 tegevust
- RLS: S1 vastutaja saab muuta S1 tulemust, mitte S2 oma; vastutaja ei saa analüüsi kinnitada ega kinnitatud analüüsi muuta; vaatleja ei saa kirjutada; admin saab kinnitada
- Staatused tabelites on arvutatud reegli 75/40 järgi
